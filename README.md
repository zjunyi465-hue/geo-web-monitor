# GEO Web Monitor

**在自己的电脑上，观察品牌如何出现在 AI 网页回答中。**

使用 Node.js、SQLite 和 Playwright，保存网页回答、页面来源及截图，再查看历史记录、数据报告和前后变化。[English introduction](docs/README.en.md)。

运行基线：**Windows + Microsoft Edge + Node.js 24+**。默认仅供本机访问，需要使用者自己的平台账号并手动完成登录、验证。支持两个主流中文 AI 网页版，公开包使用“平台 A / B”标签；目标网址与适配规则见[网页适配器](src/browser.js)。通用标签不隐藏源码中的技术接入信息。

## 能做什么

| 功能 | 用途 |
| --- | --- |
| 品牌资料 | 保存名称、别名、介绍和官网，竞品选填 |
| 问题池 | 手动或按行批量输入问题，规则模板生成后人工审核；按[专题](docs/question-topics.md)整理 |
| 平台账号池 | 多账号独立浏览器资料、名称及备注编辑、[登录状态检查](docs/account-login-check.md) |
| 监测任务 | 手动选择问题与账号，或每日/每周执行；单账号串行，最多两个账号并行 |
| 采集结果 | 原回答、来源、截图、失败原因和执行历史；[人工复核](docs/answer-review.md)与原文片段 |
| [历史回答检索](docs/answer-search.md) | 按字面查找名称、词句或网址，查看高亮片段和完整保存内容 |
| [分析报告](docs/analytics-report.md) | 品牌名称出现、来源分布、问题/平台/账号比较及历史采样，追溯原文证据 |
| [信源资产库](docs/source-library.md) | 分开整理正文引用和搜索来源，人工分类、收藏及备注 |
| [机构发现与对照](docs/institution-discovery.md) | 从保存内容提取候选名称，人工确认、合并别名，并在同一批样本中比较 |
| [变化动态](docs/change-feed.md) | 查看相邻回答的名称与保存来源差异，标明条件是否确认，展开前后原文 |
| 团队 | 管理员添加成员；登录成员共用这个实例的项目数据，没有项目隔离 |

手动任务保存问题组，每次执行另选账号；定期任务预设执行账号。专题成员变动不会自动改写已保存任务。

## 开始使用

安装 Node.js 24+ 和 Edge，下载仓库并解压，在项目目录打开终端：

```powershell
npm install
npm run doctor
npm start
```

pnpm 用户可用 `pnpm install --frozen-lockfile`、`pnpm doctor`、`pnpm start`。

保持终端运行，打开 <http://127.0.0.1:8790>：创建管理员 → 添加品牌 → 保存一个问题 → 在账号池打开专用窗口并登录 → 创建手动任务 → 选择问题与账号运行 → 核对原回答、来源和截图。

首次只测试一个问题和一个账号，确认采集结果与同一次原网页相符后再扩大批次。[完整运行教程](docs/quickstart.md)包含端口设置、停止服务、定期执行与备份。

## 怎样理解结果

- 名称出现不等于推荐、认可或排名。主动提及率以不含我方品牌名称的推荐类有效回答为分母；失败、空正文和已知重复归属不当作品牌未提及。
- 来源只说明页面展示了链接，不证明它支持每句话。正文引用与搜索结果分别保存；来源未采集完整时保留缺口，不补造链接。
- 情感是关键词粗判，可能混入其他机构的评价。人工复核是团队判断，不覆盖原统计，也不是自动事实核验。
- 变化动态只检测名称出现和保存来源集合的变化。条件未确认的记录只能作原文对照，不混入同条件趋势；没有这类变化不代表全文相同。

具体分母与边界见[报告口径](docs/analytics-report.md)。所有演示图使用虚构数据和模拟回答，不是平台效果证明。

## 使用边界与隐私

账号使用独立持久浏览器资料，平台仍可能使登录失效或要求验证。程序不会代填验证码；处理后按[重试与继续说明](docs/retry-behavior.md)操作。Windows 监测窗口尝试在后台打开，窗口行为与平台页面仍需在自己的环境核对。

定期任务需要电脑开机、服务运行。本版没有开机自启、任务守护、成员项目隔离或公网部署保障；内容创作与发布、自动事实核验也未实现。网页改版、网络限制及长回答可能导致采集失败或不完整。

数据库、浏览器资料、采集截图、备份与日志应留在本机。Cookie和浏览器资料属于敏感登录凭证；备份也包含业务数据，不应公开。见[隐私说明](docs/privacy.md)。

项目与接入平台无官方关联。请使用自己拥有或获授权的账号和数据，并遵守目标平台规则。[MIT许可](LICENSE)覆盖本项目代码，不授予第三方服务或内容的使用权限，也不保证回答正确或排名提升。

## 开发与验证

```powershell
npm test
npm run demo
```

`demo` 生成模拟回答，不向真实平台提问。最新公开候选的同机隔离回归：107项中93通过、0失败、14项可选测试跳过；这不代替新电脑安装和真实账号验收。[验证范围与可选测试](docs/validation.md)。

代码入口：`src/server.js`（服务与接口）、`src/browser.js`（网页适配）、`src/db.js`（数据库）、`public/`（界面）。[架构与扩展](docs/architecture.md)提供完整模块说明。
