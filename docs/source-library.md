# 信源资产库

从有效成功回答的已保存链接动态整理，不访问外部网站、不额外发问。侧栏进入信源资产库，选择品牌、任务、问题、平台、日期或来源类型。搜索匹配标题、链接、域名和手动备注；分类和收藏也可筛选。

先按网站主机名汇总（去除 www 前缀，不自动合并其他子域），每页12个网站；点击网站查看页面，每页20条。完整URL相同的链接合并，查询参数和其他URL差异保留。同一回答重复编号或链接不增加覆盖次数。每个网站的正文引用与搜索结果分别按回答去重；同一回答可能同时属于两种类型，不能相加。非HTTP(S)或含用户名密码的链接不纳入。

仅纳入正文非空且归属没有已知重复冲突的成功结果，重试尝试记录不重复累计。失败或缺失不证明平台未引用；搜索结果不混成正文引用。时间取当前筛选中结果保存的取得时间，不是网页发布时间或更新时间。链接出现和覆盖次数不证明权威性、内容正确或可访问性。

点击编辑可手动标记待分类、自有内容、第三方、竞品相关、待核实，收藏并填写备注（长度上限2000个UTF-16单位）。标注按品牌与精确URL保存，属于团队共享资料；同一URL在另一品牌下不继承标注。全部默认待分类，不根据域名自动判归属。不同成员修改采用最后一次保存的内容。筛选不会删标注或修改原始回答。

查看回答按当前筛选追溯对应的正文引用/搜索结果记录，每页10条，展开可看问题、账号、原文与取得时间，并可进入完整执行记录。来源证据包含实际原文，只能登录后访问。暂无数据时调整筛选或完成新监测；重新进入页面即可更新来源，不需要手动导入。

标注存储在 source_annotations 表，已有数据库启动时自动创建，原有结果表不改写。数据库备份包含该表；真实运行数据、标注和截图不加入公开代码包。

搜索匹配当前筛选范围内同一URL历次取得的标题，显示标题取最近保存的非空标题。无效筛选不会替换已加载的数据范围；编辑草稿在查看/关闭来源证据时保留，取消编辑不修改列表标注。

跨模块切换品牌后，重新进入信源库或报告时会清除上一品牌的筛选和证据状态，信源编辑草稿不跨品牌带入。人工标注仍按品牌保存，切回原品牌后可查看。报告和信源库的筛选提交成功后才替换已加载范围。

异常URL类型或不符合原始HTTP(S)格式的链接不纳入；无效日期不会使列表整体失败。没有可判定运行日期的记录不进入日期筛选，取得时间无法确认时显示未知。不同时间偏移会规范到同一实际时刻进行排序。重新加载列表会清除旧证据面板，查看回答时重新取当前保存的结果。
