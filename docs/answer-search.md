# 历史回答检索

结果列表在限制高度的区域内滚动，分页控件放在列表外，每页20条，记录增多不会让整个页面按记录数增长。列表可用鼠标或聚焦后的键盘滚动；原文面板也独立限高，桌面并排、窄屏上下排列。展开长原文或来源仍在相应区域中查看，不截断保存内容。

在侧栏打开“历史回答检索”，选择品牌，输入名称、词句或网址，点击“搜索”。按任务、平台、账号、问题、当前专题和北京时间的运行开始日期缩小范围；品牌切换和未提交输入的行为见下方“页面操作”。

## 检索范围

- 回答正文及保存来源：正文、正文引用标题/链接、搜索结果标题/链接。
- 仅回答正文、仅正文引用、仅搜索结果：分别独立检索，不混入问题文字、机构人工名单、备注或错误日志。
- 按连续字面内容匹配；英文大小写不区分。输入 `[a+b]` 就搜索这几个字面字符，不是正则表达式。不会自动纠正名称、展开别名、分词、做语义推断或事实判断。
- 空搜索词显示引导，不默认返回所有原文。搜索词最多200个UTF-16单位，首尾空白去除，内部空白和标点保留。

## 计数和证据

只检索当前最终结果表中状态成功且正文非空的回答，每个结果ID列一次。执行尝试历史与失败项目仍在采集结果中查看。不同回答即使内容相同也保留；账号身份缺失或同一归属存在多条记录时，不将它们伪作独立账号或独立用户。这是检索记录数，不等于分析报告有效样本数、品牌提及率或推荐率。

正文、正文引用、搜索结果各自统计命中的回答记录数，三个集合可重叠，不能相加。引用来源只使用已保存的有效HTTP(S)链接，带凭证、异常链接和损坏的JSON不作为可打开来源；每类相同URL和标题的重复条目合并，查询参数不同、标题不同或来源类型不同的记录保留。来源标题命中不表示品牌在回答正文出现。

结果按运行开始时间从新到旧、结果ID倒序排列，每页20条；时间未知的记录排最后，指定日期范围时排除。未知账号保持未知，不通过当前账号名称推测过去身份。任务名称优先使用历史任务快照。专题使用当前问题成员，空专题返回空结果。

每条回答最多预览3段正文和每类5条匹配来源。原文位置使用保存文本的偏移，不改变换行或文字；大量命中时最多高亮前200处，完整正文仍然保留。点击“展开原文及来源”可查看完整保存正文及可用来源；证据接口再次检查当前品牌和检索范围，记录删除或不再匹配时提示重新搜索。点击“查看完整运行”定位到该条回答，返回检索页保留已应用的搜索和页码。

HTML仅按原文字显示，不执行回答中的标签。来源没有经过可访问性或事实核验；检索没有命中只能说明当前保存内容没有匹配，不能推断真实平台没有提及、没有引用或没有搜索。搜索不会访问外链、发送AI问题或修改回答。团队成员在登录后共用已有项目数据。

刷新时若所选专题已经删除，会保留失效范围并提示重新选择，不自动展开成所有问题。当前账号池里已没有的历史账号筛选仍显示对应编号，便于检查旧记录。结果区明确显示实际应用的搜索词；尚未提交的新输入或失败的搜索不会被冒充为当前结果。返回检索页及刷新不读取此前已删除的运行详情。

## 页面操作

主要搜索区展示搜索词、品牌、范围和平台。“更多筛选”可以展开任务、账号、问题、专题和日期；折叠仅影响显示，不取消已应用条件。四个数字分别展示全部命中、正文、正文引用及搜索来源命中的回答记录数。命中片段优先显示，其他片段和参考来源可展开；仅来源命中时直接展示来源，不插入虚构正文。

尚未提交的新输入在打开/关闭原文、翻页及返回页面时保留，结果仍按已应用条件展示；点击搜索才应用新输入。切换品牌会先加载该品牌的问题和专题选项并清空旧品牌依赖范围，加载失败恢复原选择；实际结果品牌只在搜索成功后改变。清空筛选撤销未提交输入并返回当前结果品牌的初始搜索状态。
