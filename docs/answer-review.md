# 回答人工复核

在“采集结果”查看一次运行，展开成功回答，点击“人工复核”。可以保存待复核、准确、有误、信息过时或无法确认，填写备注（上限2000个UTF-16单位）；在复核原文中选取片段后点击“引用选中的原文”，上限4000个UTF-16单位。引用保留具体位置，同样的文字出现多次时不会自动选另一次。片段只是说明判断位置，状态针对这条完整回答。建议备注说明判断依据及资料日期。

这是团队人工判断，不是系统自动事实验证、推荐判断或整体准确率。原始回答、链接、截图、提及次数、来源统计和情感粗判不会被复核标记修改。待复核可以保存备注，不当作已完成判断。

团队成员共享同一条回答的最新复核，记录最后保存者和时间。本版不保存完整复核修改历史。多人同时编辑时，保存会检查复核更新时间和回答版本；冲突返回提示，当前草稿保留，需要复制或重新打开核对后再保存，不自动覆盖他人的记录。

编辑期间暂停正在复核的运行结果页自动刷新，后台监测继续。切到其他运行时自动刷新正常，返回原运行仍保留草稿。手动刷新保留编辑内容；保存成功后保持对应回答展开。保存成功但页面刷新失败时，会明确提示已保存，可稍后刷新核对；不会把已保存误报为保存失败。关闭编辑后自动刷新恢复。

复核绑定结果编号及内容版本，包括回答正文、保存的正文引用和搜索来源，以及运行、问题、平台、账号和状态。回答或来源变化时，原复核的备注和引用保留供核对，生效状态改为待复核，并显示需要更新。旧引用不冒充新回答中的片段。重新复核需要重新读取当前版本；失效记录不会自动沿用原判断。即使只是来源列表顺序或保存格式变化，也会保守要求重新核对。

“分析报告”单列人工复核数据，遵循当前品牌、任务、专题、日期、平台、账号等筛选，只计报告中的有效成功回答，空正文、失败和归属不唯一样本不计入。待复核、准确、有误、信息过时、无法确认五类相加等于该范围有效回答数；已复核数不包含待复核。原文变化记录属于待复核的一个子集，不重复加入总数。点击各类数量可以查看相应回答，进入完整运行即可编辑。报告不把这些主观分类合并为“AI准确率”。

引用在保存时核对原文偏移与文本完全一致，拒绝伪造、超出范围和截断代理字符。所有备注与原文仅作为文字显示。仅登录成员可读写，写入沿用站点来源检查。只能编辑有效成功的非空回答；原始采集记录仍按原工作流管理。

本地表 `answer_reviews` 保存最新复核元数据，随数据库备份恢复；删除对应结果会删除其复核，避免结果编号复用时继承旧记录。该表、真实备注和原文片段不进入公开代码候选包。
