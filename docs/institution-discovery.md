# 回答中的机构发现与对照

只读取已有监测结果，不访问机构网站，不发额外问题。中文名称结构规则从正文和有效HTTP(S)来源标题提取候选，泛称与描述句尽量过滤；不等于完整实体识别，可能误识别、遗漏，英语简称等可手动补充。候选默认待确认，不自动认定竞品或推荐。人工补充名称必须在该品牌有效正文或标题中出现。

机构核对记录独立按品牌保存，团队共享；分类为待确认、关注对标、不关注、识别错误。合并将名称作为目标别名，合并后的分组使用目标分类，子名称原分类与备注保留。保持独立可解除合并；拒绝自合并和循环。编辑时核对版本避免覆盖他人保存。原回答不改。

同一运行问题账号槽位冲突、失败、空正文均排除。当前筛选的成功回答为有效样本；公共比较分母仅为推荐类且问题不点名当前我方名称或任何人工确认对标及别名的回答。其他问题单列，不推断缺失类型。所有对标共用公共分母，同一条回答多别名只算一次。正文、引用标题、搜索标题独立计数；标题不提高正文出现率。四象限为双方匹配、仅对方、仅我方、双方未匹配，后一项不证明没有其他机构或无识别遗漏。

按当前品牌资料与当前人工确认名单回看历史，名字、归类与合并变更会重算历史视图，不改保存回答。不是历史市场份额、真实排名、推荐评分或因果推断，重复账号采样不代表独立用户。任务、平台、账号、当前专题成员和运行开始日期筛选影响样本；候选名称搜索与分类仅筛候选列表，不改变公共比较分母。来源仅包含已取得的链接，完整性与事实仍需核对。

候选每页20组，证据每页10条；问题表前30行及前8家对标均标限制。点击证据可看名称原文高亮、完整回答、已保存引用/搜索链接并进入完整运行。备注与原文转义显示，不执行回答HTML。品牌切换、筛选及分页请求成功后才提交界面状态。

数据表 institution_reviews 保存核对分类、合并关系、备注与时间，随本地数据库备份。它不保存平台密码，不随公开候选导出。

## 机构详情

点击机构名称后的“详情”打开单独视图，沿用任务、平台、账号、当前专题成员及运行开始日期范围；候选名称搜索和分类不改变详情样本。返回列表保留原列表筛选。切换品牌、提交新范围或重载后清除旧详情及证据，避免展示过期对象。详情请求失败保留旧范围。

已确认关注对标展示共同分母下我方与对方出现数及四类共现计数，按问题、平台、账号分别展开。同回答多别名只计一次，各分组加总与详情汇总一致；问题和平台中没有出现的样本也保留。待确认、不关注或识别错误对象仅展示正文出现证据，不展示双方比较比例。比例不是推荐率或市场份额。未知账号只在同平台的“身份未知”组累计，不推测为某一实际账号。

问题与来源每页20条，原文证据每页10条；可从问题、平台、账号、来源直接查对应回答，翻页保持证据范围。问题中“对方出现而我方未出现”仅在共同有效样本中计算，点名或其他类型回答仍可查看正文，未混入比较分母。

相关来源按类型与原始URL去重，正文引用和搜索结果独立保留，同URL不同参数不合并，保留历次已取得标题。分别统计两种关联：正文提及该机构的回答使用该来源；该来源标题明确出现机构名称。次数为不同有效回答数，不是引用编号或网页数。两种关系可能重叠，也可能独立；不能据此确认来源属于该机构、支持某个论点或是推广渠道。来源证据点击后按精确URL、类型和关系筛选，不把其他回答或另一类型混入。没有取得来源时不补造、不声称平台没有参考来源，也不检查外链可访问性。

机构详情不提供历史增长或下降结论；人工归类和别名调整会重算历史，不能直接当作机构曝光变化。报告及信源资产库各自使用对应口径，机构详情不改原回答、人工信源分类或监测任务。

链接准入与信源库一致：只接受没有首尾空白、没有用户名密码的原始HTTP(S)网址；畸形链接不参与标题发现、来源计数或证据。程序接口的单问题筛选与专题当前问题集合取交集，详情汇总、分组与证据保持同一问题范围，交集为空时不回退全部。

机构分组把全名与每个已确认别名作为独立完整名称匹配。名称本身的逗号、顿号等标点不再被拆为更短别名，正文、点名排除、来源标题与原文高亮沿用同一完整名称集合。品牌资料原有的文本别名分隔规则保持兼容。
