# 问题专题

在问题池创建专题，勾选已有问题后加入或移出。一个问题可以属于多个专题；专题不复制问题。专题名称在同一品牌内唯一，跨品牌不能混用。删除专题不删除问题、任务或历史回答。

创建或编辑任务时可勾选多个专题，点击载入所选专题问题后按需要调整问题清单。重复问题只载入一次。保存后的任务保留固定问题清单，专题成员变化不会自动改变任务；任务列表提供明确确认后更新清单的入口。更新不改变历史运行快照、账号和定时设置。专题被删除后可编辑任务解除关联。运行中或等待人工处理的任务不能编辑或同步。

分析报告和信源资产库按专题当前问题成员筛选保存的历史记录；这不证明历史回答发生时属于该专题。空专题显示空结果，不回退全量；未知数据和统计分母遵守原报告规则，不补造历史结果。

专题编号不会在删除后复用，避免旧任务误关联到新专题。编号记录和专题成员随数据库备份保留；恢复后继续使用原有编号。品牌切换需问题和专题均加载成功才提交，网络失败时保留原品牌。

更新任务专题清单时核对确认时的问题清单与专题成员快照。若团队成员在确认过程中改了任务或专题，返回冲突提示，原任务和历史不变；刷新后重新确认。已删除专题在编辑页明确提示，原问题勾选保留。
