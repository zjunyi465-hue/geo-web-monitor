# 首次公开版验证范围

版本：v0.1.0 候选；检查日期：2026-10-05。此记录说明实际检查范围，不是跨环境稳定性保证。

## 公开包独立运行

在同一台 Windows 电脑上，将公开候选包复制到独立目录，重新安装依赖。没有复制原系统的数据库、账号浏览器资料、结果或登录凭证。

| 检查 | 结果 |
| --- | --- |
| npm 依赖安装 | 通过 |
| npm run doctor | Node.js 24、Windows、SQLite、Playwright、Edge 检查通过 |
| npm test | 16 项通过；12 项可选浏览器测试默认跳过 |
| npm run demo | 两个问题取得模拟回答，写入独立结果目录 |
| 可选界面测试 | 全新临时数据库、独立端口下注册管理员、品牌、问题、账号及任务界面流程通过 |
| 可选登录暂停测试 | 本地模拟页面上的登录入口、手机号输入与纯区域限制分类通过 |
| 公开文件审查 | 文件清单、哈希、禁止路径和文档链接检查通过；人工查看四张虚构演示截图 |

这些检查确认了此次同机独立目录的安装和基础流程，没有验证另一台电脑上的环境是否可用。模拟页面没有向两个主流中文 AI 网页版发问。

## 网页采集与限制

开发期间，两个主流中文 AI 网页版均有真实单题成功采集；真实回答、截图和账号资料留在本机，不随公开包分发。恢复采集、避免重复发送、账号级暂停及有窗口运行也有隔离模拟测试。

尚未完成跨电脑、跨 Windows 用户、所有地区网络、多真实账号长期连续监测和服务器部署验收。网页改版、登录失效、人机验证与长回答都可能影响采集。

使用者首次运行应选择一个问题和一个账号，核对该次原网页、保存正文、引用及截图。确认后再扩大批次。成功采集不代表 AI 事实正确。

## 执行可选检查

从项目根目录打开 PowerShell；不要设置真实运行数据路径给测试使用：

```powershell
$env:GEO_UI_TEST = "1"
node --test test/ui.test.js
$env:GEO_BROWSER_TEST = "1"
node --test --test-timeout=240000 test/browser.test.js test/resume.test.js test/login-pause.test.js
$env:GEO_WINDOW_TEST = "1"
node --test --test-timeout=180000 test/window.test.js
```

可选测试使用临时资料和本地模拟页面。有窗口测试会打开测试 Edge 窗口；它们不代表真实平台当前版本已验收。
