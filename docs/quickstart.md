# 从下载到第一次监测

教程面向 Windows 10 / 11，使用 Node.js 24+ 与 Microsoft Edge。macOS / Linux 尚未完整验收。需要自己的平台账号与可正常访问目标网页的网络。

## 1. 安装并启动

安装 Node.js 24+ 和 Edge。下载仓库 ZIP，解压到自己选定的目录，例如 `D:\Projects\geo-web-monitor`。在此目录打开 PowerShell：

```powershell
node --version
npm install
npm run doctor
npm start
```

Node.js 官方安装包通常自带 npm。pnpm 用户可用 `pnpm install --frozen-lockfile`，仓库锁文件用于固定依赖版本。第一次启动自动创建目录及空数据库，无需复制作者的数据。

## 2. 创建管理员

保持启动终端打开，访问 <http://127.0.0.1:8790>。创建自己的管理员，密码至少 10 位。这是系统账号，与两个主流中文 AI 网页版账号不同。

管理员可添加团队成员，成员共用本机数据，没有项目隔离。当前没有密码自助找回功能；不要通过删除数据库处理忘记密码，它会删除业务数据。

## 3. 品牌与问题

在品牌资料填写自己的信息，竞品选填。可参考 [虚构品牌](../examples/brand-demo.json)，该 JSON 用于示例，目前需通过页面手动填写。

问题池每行输入一个问题并保存。首次只测一个问题。模板出题可选，它不是大模型自动阅读资料生成。

## 4. 登录平台

默认账号只是系统创建的空浏览器会话，不是作者提供的账号。可添加更多账号并命名。

点击“打开登录窗口”，在专用 Edge 窗口手动登录。每个账号使用独立浏览器资料，不复用日常 Edge 的账号。系统不会自动填写手机号、验证码或完成图片验证。

在此窗口确认能正常提问，并手动选择所需搜索、思考模式。程序只尝试读取明确的页面状态，不自动切换设置；读取不到时记为未知，不能当作关闭或保持一致。

以后固定使用同一个 Windows 用户、同一个项目目录启动系统。不要让隔离环境账号、其他 Windows 用户或后台服务身份交替使用同一份 `profiles/`；浏览器加密登录资料可能无法跨用户复用。也不要同时启动两个实例使用同一份资料。登录状态仍可能被平台撤销或过期，资料文件存在不代表一定免登录。

账号名称只是系统内的标签。请在专用网页窗口核对实际登录身份；系统不会自动确认不同标签是否登录了同一个平台账号。

## 5. 运行与验收

创建手动任务，保存品牌、名称和问题，无需绑定账号。点击“选择账号运行”，选本次问题、账号，然后开始。

2 个问题 × 3 个账号 = 6 个计划采集项；成功结果才用于提及率统计。单账号串行，最多两个账号并行。出现登录或验证，任务暂停且没有处理倒计时。从任务栏打开原窗口手动处理，再点击“继续”；暂停期间不要手动发送其他问题。

结果页核对状态、正文、引用、截图和执行记录。平台 B 的正文引用与搜索结果分别列出。提及率和情感粗判不是事实核验。单题采集确认正确后，再扩大数量。

## 6. 定期执行

每天 / 每周计划需要预设自动执行账号、时间和运行日。时间按电脑本地时区计算。手动运行另选账号不会覆盖自动执行配置。

服务约每 30 秒检查到期任务；电脑关机、休眠或服务退出时无法执行。错过周期合并补跑一次，不逐次补齐历史。本版没有开机自启或后台任务守护。

## 启动、停止及换端口

以后从项目目录执行 `npm start`，保持终端打开；停止时按 Ctrl+C。Windows 可执行辅助脚本：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

端口占用时：

```powershell
$env:GEO_PORT = "8791"
npm start
```

改为访问 <http://127.0.0.1:8791>。不要同时启动两个实例使用同一数据库和浏览器资料。

## 配置

以下变量在启动前设置。项目**不自动读取 .env**，无需修改源代码。

| 变量 | 默认 | 含义 |
| --- | --- | --- |
| GEO_PORT | 8790 | 本地端口 |
| GEO_HOST | 127.0.0.1 | 保持本机监听，不直接暴露公网 |
| GEO_DB_PATH | data/geo-monitor.db | 数据库文件 |
| GEO_PROFILE_ROOT | profiles | 浏览器资料目录 |
| GEO_RESULTS_ROOT | results | 截图目录 |
| GEO_BROWSER_CHANNEL | msedge | Edge 为验收基线 |
| GEO_HEADLESS | 未设置 | 默认可见；1 是测试用无窗口模式 |

相对路径按启动目录解析，所以从项目根目录启动。无窗口模式不适合需要人工登录验证的流程。

## 备份与恢复

任务空闲时执行 `npm run backup`，输出到 backups。备份包含数据库和截图，不包含平台登录资料。恢复前停止服务，将备份数据库和 results 放回相应位置；可能需要重新登录。

备份命令默认读取默认数据位置；自定义路径时，调用 `src/backup.js` 导出的 `createBackup` 并传入对应路径。

遇到问题看 [排错指南](troubleshooting.md)。服务器部署不在本教程范围内，不能仅改变 GEO_HOST 就上线公网。
