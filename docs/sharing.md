## 主推文

我做了一个能在自己电脑上运行的 GEO 监测基础款，准备开源。

想解决的问题很简单：同一个问题，两个主流中文 AI 网页版到底有没有提到你的品牌？引用了哪些网页？

它用 Playwright 操作网页，保存回答、来源和截图；支持多账号、手动与定期监测。

安装步骤和模块原理都写进仓库，方便复刻、学习和继续开发。

## 可选后续串文

1. 我为什么从网页问答开始：模型 API 和网页产品的设置及会话环境可能不同，结果不能直接等同。这个项目只记录自己账号看到的网页输出，不代表所有用户的体验。
2. 使用流程：品牌资料 → 问题池 → 本次选择账号 → 采集 → 查看原文、来源及基础指标。账号资料相互独立，换账号不必编辑手动任务。
3. 原理：Node.js 本地服务、SQLite 保存数据、Playwright 操作浏览器。两个主流中文 AI 网页版的正文及来源处理分别实现。
4. 我踩过的坑：验证码处理后，应先检查原问题是否已经发送；账号心跳失败不一定代表问答失败；截图里的内容不一定都位于真实窗口范围内。
5. 第一版边界：默认 Windows / Edge、本机运行，需要用户手动登录及验证。情感是粗判，网页改版仍可能影响采集。内容生产和服务器部署没有包含。
6. 欢迎用虚构数据复刻，也欢迎提交脱敏的复现步骤。MIT 许可，可以继续做成自己的项目。[公开后填入仓库链接]
