# 虚构演示素材

README 与分享素材全部由 `npm run media:demo` 生成。脚本启动隔离临时数据库和本地服务，填入虚构品牌、问题及模拟回答，用无窗口 Edge 截图。

不会读取现有 data、profiles、results，不连接两个主流中文 AI 网页版，也不发送真实问题。临时演示管理员凭证只用于该临时进程，退出后不属于任何真实账号。

输出：`docs/assets/overview.png`、`accounts.png`、`run-selection.png`、`report.png`。这些截图只演示软件界面，不证明 AI 平台效果。对应数据在界面中标注“虚构演示 / 模拟回答”。

拍摄视频可采用：工作台 → 品牌资料 → 问题池 → 账号池 → 选择问题与账号 → 结果与来源。真实平台登录、手机号、验证码、客户资料和私有浏览器标签不应出现在公开视频里。
