# 产品路线

## 第一版：本机网页监测

品牌资料、管理员与成员、问题池、两个主流中文 AI 网页版的回答采集、手动/定时任务、原始结果和基础报告。

两个主流中文 AI 网页版均有真实单题采集记录；账号池、手动运行选择、定期任务、恢复及分页均已实现。不同账号、网络与长批次的稳定性需要使用者自行验收，不将少量成功样本当作通用稳定保证。

## 第二版：诊断深化

当前已支持人工复核、来源台账、确认后的机构对照、同题历史、历史回答检索和站内变化动态。下一步可以继续改善长期采集稳定性、结果检索和证据阅读；新增功能需另行评估。现有名称出现不等于推荐，不自动核验事实或证明优化效果。

## 第三版：内容与发布

可探索监测资料辅助选题、系统内创作与审核、发布渠道接入及发布 URL 回填。这些属于后续设想，当前没有实现；同题复测也不能单凭数值变化归因于某篇内容。

## 使用者可自行扩展：服务器部署

把浏览器执行器与 Web 服务分离，增加 HTTPS、持久任务队列、用户隔离、备份和权限细化。开源本机版仍可独立使用。
