# 重试与继续的区别

“重试失败项”使用原运行的账号和问题配置，只重做失败项。它会清除这些失败项的旧提交检查点，进入新对话重新提问，可能在平台历史中留下重复问题。旧尝试、截图和错误记录保留，成功结果保持原样；报告使用最新结果。

“处理后继续运行”用于登录或验证暂停及中断恢复，优先核对原问答并继续采集，不擅自重发已尝试提交的问题。原对话无法确认时停止，再由使用者选择新会话重试。

采集依赖实际浏览器页面。最小化或切换到其他窗口不会主动停止程序；关闭问答标签或对应Edge采集窗口会中断当前问答，失败提示BROWSER_CLOSED。已经保存的结果保留，登录资料也不会因为关闭窗口而被清除。关闭本地GEO系统的前端网页，后台服务仍可继续；关闭电脑或后台服务则会中断执行。

测试使用隔离数据库和本地模拟页面；实际账号仍需自行单题核对。

数据库写入遇到短暂的外部连接占用时，每次最多等待3秒。任务失败后的中断状态保存也有独立异常保护，保存再失败时写服务错误日志，不让该次异常直接退出服务。持续锁定或存储故障仍不能保证结果落盘，应在解除占用后核对运行记录；不把无法保存的结果当作成功。
